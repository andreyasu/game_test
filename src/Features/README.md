`Features` — директория для игровых фичей: конкретные юниты и переиспользуемые
действия, из которых они собираются.

- `Actions/` — строительные блоки поведения (`MeleeAttack`, `RangedAttack`, `Heal`,
  `MoveToTarget`, `ExplodeIfEnemyNear`, общий помощник `Combat`). Новый юнит обычно
  переиспользует готовые действия; принципиально новая механика — это новый класс
  `IAction` здесь же.
- `Swordsman`, `Hunter`, … — сами юниты. Каждый — это `UnitTraits` (что он есть) плюс
  список действий (что он делает), всё в конструкторе.

Код в `Features/` опирается на возможности `Core/` и никогда его не меняет.
